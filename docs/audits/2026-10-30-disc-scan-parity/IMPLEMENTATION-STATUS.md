# Scanner audit: P0/P1 implementation follow-up

This follows the [frozen 491-disc audit](README.md). It describes the implementation
on branch `fix/scanner-audit-priorities`, not a deployment or a released scanner
version. The implementation and this follow-up are versioned together. The
original audit and its ledgers remain unchanged.

**The capture-independent fixes are implemented. Capture-dependent navigation
remediation remains blocked.** Scanner defaults, MakeMKV fallback and the rollout
gate have not changed. No fresh physical-disc scans or playback checks occurred.

## Continue on a machine with a disc drive

Use the .NET 10 SDK and sibling `web`, `tools` and `data` checkouts. Fetch and
check out `fix/scanner-audit-priorities` in **web**. The audited tools revision is
`acf147b0e5641ceebf56acfd00bee8feb9ac6bfb`; its OdmScanner references the sibling
web projects directly, so rebuild it against this branch rather than using an
older published executable.

From the parent workspace, with the intended disc mounted at `D:\`:

```powershell
dotnet build .\tools\tools\OdmScanner\OdmScanner.csproj /p:NuGetAudit=false
dotnet run --no-build --project .\tools\tools\OdmScanner -- list
dotnet run --no-build --project .\tools\tools\OdmScanner -- scan D:\ `
  --data-repo .\data --output C:\scanner-runs\priority-disc\initial
```

Replace the drive/output with the actual disc and a new per-disc output directory;
existing outputs are not overwritten. Use the capture priorities below.
Keep each complete output folder, especially `capture.json`, `manifest.odm.json`
and both reports. A capture can be replayed after generator changes without
reinserting the disc. See `tools\tools\OdmScanner\README.md` for reference selection,
capture/replay commands and exit codes.

The audit results travel with this branch; the private original raw corpus and
session-only replay harness do not. New captures should stay outside the source
repositories and be reviewed for private paths or other sensitive metadata before
sharing. No local NuGet feed overrides, credentials or application secrets are
included in this work.

## Recommendation status

| Recommendation | Implementation and remaining boundary |
|---|---|
| P0: comparison persistence | Added explicit ETag-conditional create/replace operations without changing create-only `Save`. Appends retry conflicts, retain the newest 20 records and reject invalid existing histories. Storage failures and cancellation are not reported as successful persistence. |
| P0: truthful outcomes and provenance | Bulk actions distinguish attempted, computed, persisted, skipped, failed and computed-error records. Runs record comparer build plus SHA-256 of the original log and manifest bytes, before decoding. Admin details expose that provenance. |
| P1: DVD audio-format decoding | Raw codes now map to 0 AC-3, 2 MPEG-1, 3 MPEG-2 extension, 4 LPCM, 6 DTS and 7 SDDS; reserved 1/5 remain Unknown. Ordering and unrelated stream attributes are preserved. Existing saved manifests are not regenerated by this fix. |
| P1: versioned usefulness reporting | Added metadata usefulness v1 alongside unchanged technical/strict/graded-v1 definitions. Dashboard, cohorts and details distinguish known useful choices, required-choice review, complete-known-useful discs, unclassified content, acquisition review and unmeasured history. Conservative source/map/byte/duration evidence is retained per choice; material boundaries, timing, angles and ambiguous occurrences remain review states. |
| P1: semantic stream identity and source safety | Import/projection retains native PID, category, codec/coding/format/rate metadata and explicit source provenance. ISO language aliases normalize at projection/comparison boundaries. Identify dialogs expose language and available PID. Existing log-first protection for identified discs with both uploads is unchanged; no saved ordinals are migrated. Persistent per-disc source selection and a validated cross-source semantic migration are not introduced. |
| P1/P2: declared captions | Line 21 declarations survive import/projection and appear as explicitly declared caption capability. No fabricated subtitle rows, derived audio cores or forced-only duplicates are added. Caption payload/playback remains unverified. |
| P1: navigation, independent boundaries and authored timing | Blocked pending real navigation captures. No blanket splitting, timing tolerance expansion, replacement of authored ranges, or removal of angle/subpath safety guards was applied. |

The live usefulness report conservatively treats every saved identification as
useful. It does not infer incidental content from names or duration. Its totals
therefore need not equal the original audit, which explicitly classified 98
incidental declarations. Known-label coverage is not semantic-stream recall or
whole-disc completeness. Historical runs without usefulness v1 remain unmeasured.
New language/PID/caption UI metadata is not silently folded into legacy v1 scores.

SDDS code 7 was independently established during implementation by VideoLAN's
[libdvdnav `dvd_types.h`](https://code.videolan.org/videolan/libdvdnav/-/raw/master/src/dvdnav/dvd_types.h),
which defines `DVD_AUDIO_FORMAT_SDDS = 7`. This supplements, rather than rewrites,
the original audit's narrower independently verified mapping.
